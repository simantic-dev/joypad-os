# PR 305 targeted: switch_bt pair over CDC + live console link on LED
Verdict: COULD NOT SIMULATE.
Why: the change is gated on CONFIG_BT_CLASSIC_OUTPUT (Pico W universal switch_bt build; src/CMakeLists.txt:2249 in the PR) and REQUIRE_BLE_OUTPUT. The nRF bt2usb build has neither: its ELF contains no BLE.PAIR / BLE.MODE strings, so the new cmd_ble_pair branch is not compiled in. The LED part is the CYW43 GPIO LED. Exercising it needs a Pico W with a CYW43 Bluetooth HCI controller emulated and a Switch as BR/EDR host (Classic pairing/sync), neither of which pyrite models (no BR/EDR radio; CYW43 BT HCI missing). The existing nRF/RP2040 scenarios do not touch the changed lines (results/305/verdict.md: not_exercised stands). The PR itself says the CDC pairing path was not exercised end to end on hardware.
